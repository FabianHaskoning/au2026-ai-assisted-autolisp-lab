# Showcases

Two complete AutoLISP applications, here to be read, run and taken apart.
Neither is an exercise — they're what the patterns in the tracks look like
once they've grown up.

| Showcase | Can you run it here? | What it shows |
| --- | --- | --- |
| [Roundabout](roundabout/README.md) | **Yes** — one `APPLOAD` and a blank drawing | A full design tool: a dialog, layers, geometry, and a command that reads back a roundabout it drew earlier |
| [Cadastral map](cadastral-map/README.md) | **No** — it needs a plugin and a live web service | Real production code, contributed by the engineer who uses it. Here to read, not to run |

**New to all this?** Start with the roundabout. Load it, type `ROUNDABOUT`,
watch it draw — then open the files and ask your assistant what any of it
means. Full instructions on its own page.

**Want to see what "in production" looks like?** The cadastral map is honest
about the parts the workshop can't teach you: a web request, a data format
AutoLISP can't parse, and a dependency on somebody else's plugin.
