## Doing this on your own machine

Everything here works on any Windows PC with AutoCAD, VS Code and a browser —
the assistant is whichever one you already have an account for, and the
boilerplate prompt does the rest. You do not need the lab VM.

## Running the session yourself

The other half of the lab — the provisioning scripts that built the VM, the
verification self-test, the assistant configuration, the take-home setup and
the facilitator guide — lives on the
[`facilitator`](https://github.com/FabianHaskoning/au2026-ai-assisted-autolisp-lab/tree/facilitator)
branch. Track 3's
[`workshop-in-a-box.md`](tracks/3-teach-and-scale/workshop-in-a-box.md) is the
honest account of what it costs to run.
